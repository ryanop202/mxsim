# refs/rbt/ — Assets RBT (2024 RBT SX TRACK)

Fichiers extraits d’une piste RBT fournie pour le décor et l’ambiance.

## Contenu

| Fichier | Description |
|---------|-------------|
| billboards | Positions des billboards |
| decals | Decals (sable, ornières, herbe…) |
| desc | Description ("2024 RBT SX TRACK") |
| edinfo | Gradients / points d’élévation |
| lighting | Soleil, ambient, fog, skybox |
| statues | Arbres, herbe, objets de décor |
| terrain.hf / terrain.png | Heightmap |
| tileinfo / tilemap | Tiles et physique |
| texturelist | Textures PPM |
| shading.ppm / shadingx2.ppm | Shading |
| timing_gates | Grilles et checkpoints |
| fastlap.mxdemo / lastlap.mxdemo | Demos de tour |

## Usage

Ces fichiers servent pour :
- **herbe / arbres / eau / décor / ambiance**
- billboards, statues, decals d’ambiance
- lighting / sky

Ne pas utiliser pour les whoops ni les berms (réservés à JGSX).
